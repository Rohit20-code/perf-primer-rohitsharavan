## Learned
- Every HTTP request stands alone. "Being logged in" only works because a cookie or token is sent every time.
- A cookie is sent back automatically; a bearer token has to be added by the client to every request. In JMeter that means a Cookie Manager for one and extracting the token for the other.
- A 200 status doesn't prove a request worked. Check the body too, which is what an assertion is for.
- TTFB ("Waiting for server response") is the phase that shows the server's own processing time.
